### Sistema de Gestión de Turnos para Clínica


### Tecnologías Utilizadas

* Java 17*
* Spring Boot 4 (Framework principal)
* Spring Security (Autenticación y control de acceso por roles)
* Spring Data JPA / Hibernate (Persistencia de datos)
* MySQL (Base de datos relacional)
* Thymeleaf (Motor de plantillas HTML para el Front-End)
* Bootstrap (Estilos y diseño de la interfaz)
* **Maven** (Gestor de dependencias)

##  Perfiles del Sistema

El sistema cuenta con dos niveles de acceso principales:
1. Administrador Tiene a su cargo la gestión total del sistema (altas, bajas y modificaciones de pacientes, profesionales, especialidades, obras sociales, días, horarios y la asignación/anulación de turnos).
2. Profesional Acceso de consulta exclusiva a su propia agenda de turnos y posibilidad de cambiar su contraseña.
